## 怎么用

1. 先截图,**再打码**。每一行都写了必须遮盖什么,客人姓名、电话、邮箱、金额、订单号、网盘提取码一律不能留。
2. 按「建议文件名」那一列命名,放进 `images/`。
3. **刷新页面就显示了,`index.html` 一行都不用改**——并且每张放进来的图自动支持点击放大(全站统一的纯 CSS 灯箱)。

### 扩展名:.png 和 .jpg 都行

页面对每一处都做了两级回退:先找 `.png`,找不到就自动去找同名 `.jpg`,再找不到才显示虚线占位框。
所以清单里虽然写的是 `.png`,你**直接放同名 `.jpg` 也一样会显示**,不需要转换格式。

### 体积提醒(重要)

- **单张控制在 300 KB 以内。**
- **手机截图请保持原始 JPG,不要转成 PNG。** 同一张手机截图转 PNG 会胖 5–8 倍(实测 143 KB → 917 KB)。
- 图片一旦提交进 Git 并推到 GitHub,历史里就永远存在,删掉当前版本也没用——**又大又删不掉**。

## 尺寸怎么理解

- `1600×900` / `1400×900` / `1200×900`:电脑端页面,浏览器窗口拉到接近这个比例再截,不用像素级精确。
- `780×1688`:手机真机截图(= 390×844 逻辑尺寸 × 2 倍视网膜屏),iPhone 竖屏原图直接用即可(**保持 JPG,别转 PNG**)。★必须竖屏★——横屏或桌面浏览器窗口冒充的图,和已入库的 App 图一眼看得出不同。

## v15.0 新增约定

### 一处占位挂多张图(多图轮播)

一个界面要分几次截才说得清时,按序号命名即可,**不需要改 HTML**:

| 第几张 | 文件名 | 说明 |
|---|---|---|
| 主图 | `<名>.png` 或 `.jpg` | 就是上表「建议文件名」那一列 |
| 第 2 张 | `<名>-2.png` 或 `.jpg` | 放进来才会出现圆点 |
| 第 3 张 | `<名>-3.png` 或 `.jpg` | |
| 第 4 张 | `<名>-4.png` 或 `.jpg` | 最多到 4 张 |

例:`guest-photo-select.jpg` + `guest-photo-select-2.jpg` → 该处出现两个圆点,
点圆点切换,点图放大时灯箱里显示的也是**当前选中的那一张**。

- 只放主图 = 零圆点,外观和以前完全一样,不会多出任何东西。
- v15 已经为 4 处预置好 2 图结构:`guest-photo-select`(×2 处)、`guest-delivery-page`(×2 处)。
  其余占位要挂第 2 张时,下一轮把结构补上即可。

### 手机竖图(app-* 系列)

`app-*` 的 10 处占位已归入竖图容器:图片按 780:1688 自然比例居中显示

还没放图的位置,虚线占位框也已经是竖比例(9:19.5),形状与将来的图一致。
