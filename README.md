# 产品作品集 · 静态站

一个产品经理作品集单页,记录「流涟旅拍 · 业务总控系统」这个项目里的产品决策。

## 这是什么

我在日本做旅拍业务,为了解决"派单靠客服挨个打电话"的问题,自己做了一套内部总控系统:
运营总控台、摄影师移动端、客人免登录交付页三端一体,打通下单 → 派单 → 拍摄 → 交付 → 结算全链路。

这个站点讲的不是功能清单,而是**五个真实的产品决策**——包含一次我自己造成的事故复盘,以及三条到现在还没解决的问题。

## 内容来源

页面文字全部来自该项目的作品集文档(`docs/portfolio/02-作品集网站文案.md`),
其中的业务数字取自 2026-08 的生产环境只读取数,未做任何估算或推演。

## 本地预览

不需要构建工具、不需要安装依赖,直接打开即可:

```bash
# 方式一:双击 index.html,或
open index.html

# 方式二:起一个本地服务(推荐,避免个别浏览器的本地文件限制)
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术说明

纯静态,无框架、无 CDN、无构建步骤:

```
index.html    单页全部内容
style.css     样式(深色、响应式,断点 768px)
.nojekyll     关闭 GitHub Pages 的 Jekyll 处理
```

- 零 JavaScript:平滑滚动用 CSS `scroll-behavior` 实现
- 零外部资源:字体走系统字体栈,无图片素材
- 支持打印:已针对打印做浅色适配,可直接导出 PDF

## 部署

托管于 GitHub Pages。仓库设置 → Pages → 选择 `main` 分支根目录即可。
